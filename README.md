# 123秒传

在线访问：https://xjxjj.ccwu.cc/

123云盘 · 秒传链接生成与转存工具

## 功能介绍

### 🔐 账号登录
- 支持 123 云盘账号密码登录
- 记住账号密码功能

### ☁️ 网盘文件
- 浏览 123 云盘文件列表
- 支持搜索文件名
- 选择文件生成秒传链接
- 一键复制秒传链接

### 📥 保存秒传
- 支持导入秒传链接批量保存到网盘
- 支持脚本 JSON 导出格式
- 失败重试功能

### 📦 批量生成
- 选择目录批量生成秒传链接
- 自动打包成 ZIP 文件下载
- 保留原目录结构
- 进度实时显示

### 🔗 分享解析
- 解析 123 云盘分享链接
- 支持带密码的分享
- 生成秒传并打包 ZIP 下载

## 使用说明

### 1. 登录
打开网站后，使用 123 云盘账号密码登录

### 2. 生成秒传
- 进入「☁️ 网盘文件」标签
- 浏览或搜索需要的文件
- 点击「选择」按钮选中文件
- 点击「生成秒传」按钮
- 复制生成的链接

### 3. 保存秒传
- 进入「📥 保存秒传」标签
- 粘贴秒传链接（支持多行批量）
- 点击「开始保存」按钮

### 4. 批量生成
- 先在「☁️ 网盘文件」进入目标文件夹
- 切换到「📦 批量生成」标签
- 点击「开始批量生成」
- 下载生成的 ZIP 文件

### 5. 解析分享
- 进入「🔗 分享解析」标签
- 粘贴分享链接
- 输入分享密码（如有）
- 点击「解析并生成秒传」
- 下载 ZIP 文件

## 格式说明

秒传链接格式：`123FLCPV2$etag#大小#文件名`

⚠️ 本工具为第三方工具，建议使用小号，不要输入重要账号密码

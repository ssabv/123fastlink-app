# 123秒传

在线访问：https://xjxjj.ccwu.cc/

123云盘 · 秒传链接生成、转存、批量分享与分享解析工具

---

## 功能介绍

### 🔐 账号登录

- 支持 123 云盘账号密码登录
- 支持记住账号密码
- 登录后自动生成并保存 `loginuuid`
- 后续文件读取、分享创建等操作复用同一登录态

> 说明：本项目使用 123 云盘网页端接口，登录态包含 `Authorization` 与 `loginuuid`。

---

### ☁️ 网盘文件

- 浏览 123 云盘文件列表
- 支持进入文件夹
- 支持搜索文件名
- 显示当前文件夹 ID
- 一键复制当前文件夹 ID
- 文件夹条目显示文件夹 ID
- 选择文件生成秒传链接
- 一键复制秒传链接

---

### 📤 批量分享

- 输入父文件夹 ID
- 自动列出该目录下的一级子文件夹
- 批量创建分享链接
- 使用网页端账号登录接口创建分享
- 自动复用登录态 token 与 loginuuid
- 支持复制单个分享结果
- 支持复制全部分享链接与提取码
- 支持导出 CSV
- 支持导出账号全部分享链接 CSV

批量分享创建分享时使用网页端接口：

```text
https://api.123278.com/b/api/share/create
```

请求体格式参考 123 云盘网页端抓包：

```json
{
  "driveId": 0,
  "expiration": "2099-12-12T08:00:00+08:00",
  "fileIdList": 123456,
  "shareName": "文件夹名称",
  "sharePwd": "",
  "event": "shareCreate",
  "fileNum": 1,
  "renameVisible": false,
  "shareModality": 4,
  "operatePlace": 1,
  "trafficLimitSwitch": 1,
  "trafficLimit": 0,
  "trafficSwitch": 1
}
```

---

### 📥 保存秒传

- 支持导入秒传链接批量保存到网盘
- 支持多行秒传链接
- 支持脚本 JSON 导出格式
- 支持失败重试

支持格式：

```text
123FLCPV2$etag#大小#文件名
etag#大小#文件名
脚本导出 JSON
```

---

### 📦 批量生成

- 选择目录批量生成秒传链接
- 自动递归扫描目录
- 自动打包成 ZIP 文件下载
- 保留原目录结构
- 进度实时显示

---

### 🔗 分享解析

- 解析 123 云盘分享链接
- 支持带密码的分享链接
- 自动获取分享内文件列表
- 生成秒传链接
- 打包 ZIP 下载

## 使用说明

### 1. 登录

打开网站后，使用 123 云盘账号密码登录。

登录成功后，系统会保存：

- token
- 用户名
- loginuuid

如果批量分享失败，可以尝试：

1. 退出登录
2. 清除缓存
3. 重新登录
4. 再次批量分享

---

### 2. 生成秒传

1. 进入「☁️ 网盘文件」标签
2. 浏览或搜索需要的文件
3. 点击「选择」按钮选中文件
4. 点击「生成秒传」按钮
5. 复制生成的链接

---

### 3. 查看/复制文件夹 ID

1. 进入「☁️ 网盘文件」标签
2. 进入目标文件夹
3. 页面会显示：

```text
当前文件夹ID：xxxxxx
```

4. 点击「复制ID」即可复制当前文件夹 ID

文件夹列表中也会显示：

```text
文件夹 · ID: xxxxxx
```

---

### 4. 批量分享一级子文件夹

1. 进入「📤 批量分享」标签
2. 输入父文件夹 ID
3. 点击「列出子文件夹」
4. 确认子文件夹列表
5. 点击「开始批量分享」
6. 分享完成后可：
   - 复制单个链接
   - 复制全部链接
   - 导出 CSV

---

### 5. 导出全部分享链接

1. 进入「📤 批量分享」标签
2. 点击：

```text
导出账号全部分享链接CSV
```

导出文件：

```text
123pan_all_shares.csv
```

字段：

```text
名称, 分享链接, 提取码
```

---

### 6. 保存秒传

1. 进入「📥 保存秒传」标签
2. 粘贴秒传链接，支持多行批量
3. 点击「开始保存」按钮
4. 如有失败项，可点击失败重试

---

### 7. 批量生成秒传

1. 先在「☁️ 网盘文件」进入目标文件夹
2. 切换到「📦 批量生成」标签
3. 点击「开始批量生成」
4. 下载生成的 ZIP 文件

---

### 8. 解析分享

1. 进入「🔗 分享解析」标签
2. 粘贴 123 云盘分享链接
3. 输入分享密码，如没有则留空
4. 点击「解析并生成秒传」
5. 下载 ZIP 文件

---

## 技术说明

### 网页端接口

本项目主要使用 123 云盘网页端接口：

```text
https://www.123pan.com/b/api/file/list/new
https://api.123278.com/b/api/share/create
```

其中分享创建接口需要：

- `Authorization: Bearer token`
- `loginuuid`
- `platform: web`
- `app-version: 3`

### loginuuid

`loginuuid` 是 123 云盘网页端请求中的重要登录态字段。

本项目会：

1. 页面初始化时自动生成 loginuuid
2. 登录请求携带 loginuuid
3. 分享创建时复用同一个 loginuuid
4. 保存到 localStorage
